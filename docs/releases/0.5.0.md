# Research Continuum 0.5.0 candidate

A local numerical research workbench with frozen multi-study campaigns and an
offline evidence browser. The candidate is implemented and runtime verified;
public release requires approval of the concrete source/asset packet.

## Included behavior

- Three original known-answer objectives: Rosenbrock, sphere and anisotropic
  quadratic. Random and grid baselines, coordinate refinement, and a fixed-step
  coordinate ablation use the same finite study engine.
- Frozen campaign inventories bind every member ledger before execution. Pause,
  resume, process-death recovery, reserved retries and all failure costs persist.
- Matched single-factor ablations and descriptive paired-seed uncertainty retain
  null/ineligible outcomes and explicitly distinguish deterministic repeats.
- Complete portable campaign bundles include all source/claim/trial/attempt
  records, raw observations, reports, checksums and stable browser selections.
- Fresh source-bound reproduction rejects unrelated cached runs. Runtime
  deviations remain explicit; reconciling a missing record claims no new execution.
- An offline browser supports study search, objective/outcome filters, cost order,
  selected trials, attempt history, best-so-far traces and complete point tables.

## Compatibility and boundaries

Use the unchanged 0.1.0 release for previously accepted 0.1 databases and bundles.
Schema-1 study fields retain their original restrictions, but source/runtime
identities are not silently migrated across releases. Version 0.5 creates new
source-bound campaigns.

This uses Python's standard library, with no network service, package installation,
model, training dataset or paid compute requirement. Built-ins share a trusted
process; arbitrary code and hostile plug-ins are not supported. Native macOS,
Windows, external 0.5 ARM64 parity, human accessibility and qualified scientific
review are not claimed.

The reported uncertainty is descriptive seed resampling, not a population
confidence guarantee or significance claim. Different objective scales are not
pooled into a winner. Original 0.1 human/native-publication gates and the broader
228-task programme retain their own unfulfilled acceptance requirements.

Original material is AGPL-3.0-only. No third-party runtime binaries, models,
datasets, private credentials or upstream implementation are bundled. See the
[workbench guide](../workbench.md) for complete first-run and reproduction commands.
